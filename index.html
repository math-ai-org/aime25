Overview

AIME25 provides the 2025 American Invitational Mathematics Examination dataset in a lightweight release format for research use. The accompanying data card documents the dataset location, intended citation, and Apache 2.0 licensing terms.

The release follows the Math-AI AIME dataset convention and is intended for evaluating mathematical reasoning systems on competition-style problems.
